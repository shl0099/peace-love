# W02 实验报告

## 1. 实验目的

验证 PyTorch MLP 训练、模型选择、确定性恢复训练，
以及 Python/C++ 数据校验的一致性。

## 2. 实验配置

- 数据集：1000 个线性可分二维样本
- 数据划分：700 / 150 / 150
- Data seed：42
- Split seed：2026
- Train seeds：0、1、2
- 模型：Linear(2,8) → ReLU → Linear(8,2)
- 参数量：42
- 训练轮数：10
- 设备：CPU

## 3. SGD 与 Adam 对比

SGD 学习率为 0.1，Adam 学习率为 0.01。

六次实验的 Test Accuracy 均为 100%。

三次实验平均值：

| 指标 | SGD | Adam |
|---|---:|---:|
| Test Accuracy | 100% | 100% |
| Test Loss | 0.01093 | 0.00252 |
| 训练耗时 | 0.0952 s | 0.1283 s |

原始实验记录：results/metrics.csv

训练耗时与测试指标来自同配置的不同次运行。
计时包含训练和验证循环，不包含程序启动和独立测试。

## 4. Resume 确定性实验

完整恢复训练状态：

- 最大预测差异：0.0
- 验收阈值：1e-5
- 结果：PASS

不恢复 Adam 内部状态：差异 3.9079566。
不恢复 DataLoader RNG 状态：差异 0.0091872。

说明恢复模型权重并不足以保证训练轨迹一致。

## 5. Python/C++ CSV 一致性测试

- 自动化测试：7 组
- 通过：7
- 失败：0

测试证据：results/csv_validation.log

## 6. 实验局限性

1. 数据集线性可分，不能代表真实复杂分类任务。
2. 训练耗时非常短，不适合据此判断优化器的普遍效率。
3. 当前实验在 CPU 上进行，Peak VRAM 不适用。
4. Resume 已在单脚本、epoch 边界场景验证，
   但尚未覆盖任意 batch 中断和独立进程恢复。
5. CSV 校验器仅支持约定的简单数值格式，不是通用 CSV 解析器。

## 7. 结论

W02 已验证 MLP 训练、固定数据划分、多 seed 实验、
最佳模型加载、确定性 Resume 和基础跨语言 CSV 校验。

这些结果为后续更复杂的机器人学习实验提供工程基础。
